# FlagsBattle — Version 1

A standalone browser prototype of an interactive flag battle.

## Run
Open `index.html` in a modern browser.

## Controls
- Tap/click a flag to give it +1 support.
- Flags bounce inside the arena.
- The last remaining flag is the winner.
- "New Battle" restarts the match.

## Next step
To connect YouTube Live, add a Node.js backend using the YouTube Live Chat API and WebSocket/Socket.IO. The backend can translate chat messages such as 🇮🇳 into support events and broadcast them to connected game clients.
